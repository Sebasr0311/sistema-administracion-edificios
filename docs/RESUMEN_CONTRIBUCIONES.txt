  --------------------------------------------------------------------------

  Merge a develop: Mar 25

  Modelos:
    src/main/java/com/edificio/admin/model/Residente.java
      Entidad Residente con atributos: nombres, apellidos, documento,

      Entidad Tutor para residentes menores de edad: nombres, documento,

      CRUD completo para tabla RESIDENTES. Incluye metodos para buscar
      por numero de documento, listar por apartamento, y busqueda textual
      por nombre/apellido. Query nativo con JOIN a APARTAMENTOS y TUTORES.

    src/main/java/com/edificio/admin/dao/ApartamentoDAO.java
      CRUD para tabla APARTAMENTOS. Incluye filtros por estado y torre,
      actualizacion de estado al asignar/desocupar.

    src/main/java/com/edificio/admin/dao/UsuarioDAO.java
      CRUD para tabla USUARIOS. Incluye autenticacion (buscar por username

    src/main/java/com/edificio/admin/dao/TipoDocumentoDAO.java
      CRUD para tabla TIPOS_DOCUMENTO. Lista los tipos de documento

    src/main/java/com/edificio/admin/dao/TutorDAO.java
      CRUD para tabla TUTORES. Incluye busqueda por documento y listado

  Services (Logica de negocio):

============================================================================
  5. TECNOLOGIAS Y HERRAMIENTAS UTILIZADAS
============================================================================

  Backend:
    - Java 17 (OpenJDK)
    - Oracle XE 18c / Oracle Autonomous Database (ATP)
    - JDBC para conexion a base de datos
    - Servidor HTTP embebido (com.sun.net.httpserver)
    - JWT (io.jsonwebtoken) para autenticacion
    - Gson para serializacion JSON
    - BCrypt para hash de contrasenas
    - ZXing para generacion de codigos QR
    - Flying Saucer (HTML a PDF) para generacion de contratos
    - Maven para gestion de dependencias

  Frontend:
    - HTML5 + CSS3 (SPA - Single Page Application)
    - JavaScript vanilla (sin frameworks)
    - html5-qrcode para escaneo QR con camara
    - SessionStorage para manejo de sesion

  Infraestructura:
    - Railway (backend)
    - Netlify (frontend)
    - Oracle ATP (base de datos en la nube)

  Control de versiones:
    - Git + GitHub
    - Ramas feature + develop + main
